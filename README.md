## 👋 About me

I’m an engineer with a background in **artificial intelligence and telecommunications**. My work connects application architecture with the infrastructure that makes it dependable: designing agent workflows, serving models, building retrieval pipelines, and operating the platforms that support them.

I enjoy working across the stack—from an API or evaluation harness down to a cluster, network, or observability layer—and turning complex systems into maintainable services.

```text
  AI agents & tools  →  retrieval & model serving  →  APIs & data
          ↓                       ↓                       ↓
  evaluation & safety     platform & automation    observability & reliability
```

## 🧠 How I approach engineering

- **Build for the full lifecycle:** design, ship, observe, test, and operate.
- **Make reliability visible:** use metrics, traces, benchmarks, and meaningful failure tests.
- **Design for safe operation:** prefer clear boundaries, least privilege, and reproducible delivery.
- **Keep systems understandable:** favor explicit interfaces, practical automation, and maintainable architecture.
